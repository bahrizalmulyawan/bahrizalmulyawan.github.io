Simpan bobot hasil training beserta jumlah epoch dan contoh tambahan.

Implementasi edukasi: filter konvolusi awal diinisialisasi untuk mendeteksi pola/tepi, sedangkan lapisan klasifikasi dilatih dengan backpropagation. Bukan pengganti model produksi.

Bagaimana cara menggunakannya?

1. PretrainBangun data sintetis angka dan latih model awal.
2. GambarBuat angka pada grid 16 × 16.
3. KoreksiPilih label yang benar lalu simpan contoh.
4. Fine-tuneLatih lagi dengan data tambahan.
5. SimpanEkspor JSON untuk dipakai lagi.

File ini mandiri dan tidak membutuhkan server, library eksternal, atau koneksi internet. Untuk hasil yang lebih kuat, gunakan dataset angka berlabel yang lebih besar dan beragam.

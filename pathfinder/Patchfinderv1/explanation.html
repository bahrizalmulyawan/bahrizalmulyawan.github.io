Patchfinder v1

Visualisasi algoritma pencarian rute terpendek pada maze/grid.

Tujuan

Patchfinder dibuat sebagai media visual untuk melihat bagaimana algoritma pathfinding bekerja, bukan hanya melihat hasil akhir rutenya.

Algoritma

  • Dijkstra
  • A*
  • Breadth-First Search (BFS)
  • Blind Search
  • Greedy Best-First Search
  • Bidirectional BFS
  • Bidirectional Dijkstra
  • Bidirectional A*
  • Uniform Cost Search (UCS)
  • IDA*

Rumus utama

Dijkstra / UCS

d(v) = min(d(v), d(u) + w(u,v))

A*

f(n) = g(n) + h(n)

Greedy Best-First

f(n) = h(n)

IDA*

f(n) = g(n) + h(n)

Maze menggunakan edge berbobot 1, sehingga BFS dan beberapa algoritma berbasis cost dapat menunjukkan perilaku yang mirip pada kondisi tertentu.

Bidirectional

Algoritma bidirectional melakukan pencarian dari dua sisi: Start dan Goal. Pencarian berhenti ketika kedua frontier bertemu.

Fitur

  • Maze Small, Medium, dan Large
  • Custom wall
  • Start dan Goal dapat dipindahkan
  • Animasi proses pencarian
  • CLI dengan perhitungan live
  • Light / Dark mode
  • Bahasa Indonesia / English
  • Responsive untuk HP dan desktop

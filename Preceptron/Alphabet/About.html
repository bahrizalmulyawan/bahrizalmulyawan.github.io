About — Perceptron OCR Huruf A–Z

Apa itu Perceptron?

Perceptron adalah model machine learning sederhana yang menghitung skor dari input dan bobot. Model ini membandingkan skor 26 kelas dan memilih kelas dengan skor tertinggi untuk memperkirakan huruf A sampai Z.

Grid gambar berukuran 16 × 16, jadi setiap gambar dikonversi menjadi 256 input biner. Setiap kelas huruf memiliki 256 bobot dan satu bias.

Demo-pretrained

Pada penggunaan pertama, aplikasi otomatis melatih model menggunakan 26 pola huruf sintetis bawaan. Ini membuat aplikasi langsung bisa dicoba tanpa training manual terlebih dahulu.

Catatan: “pretrained” di proyek ini berarti sudah dilatih pada pola sintetis demo, bukan model yang dilatih pada dataset tulisan tangan besar. Akurasi pada huruf tulisan tangan nyata bisa berbeda-beda.

Fitur

  • Menggambar huruf pada grid 16 × 16.
  • Prediksi huruf A–Z dan menampilkan skor tiap kelas.
  • Training manual dengan memilih label yang benar.
  • Training dataset demo, grafik Training Analytics, dan confusion matrix.
  • Visualisasi bobot, log perhitungan, Save/Load lokal, serta ekspor/impor JSON.
  • Mode Perceptron dan CNN-Lite untuk eksperimen edukasi.

Keterbatasan

Model demo linear dan CNN-Lite di sini merupakan alat pembelajaran, bukan OCR produksi. CNN-Lite memakai filter konvolusi tetap dan dense head yang dilatih di browser. Untuk mengenali beragam tulisan tangan, latih dengan banyak contoh berlabel dan evaluasi pada test set terpisah.

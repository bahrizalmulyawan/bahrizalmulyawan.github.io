## 📥 Tutorial Instalasi

ASM Studio merupakan aplikasi HTML yang dapat dijalankan langsung menggunakan browser.

### 1. Download repository

Clone repository menggunakan Git atau download repository melalui **Code → Download ZIP** di GitHub.

### 2. Extract file

Pastikan file utama berikut tersedia:

```text
asm_studio_responsive(6).html
```

### 3. Jalankan ASM Studio

Buka file HTML tersebut dengan browser seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge.

### 4. Selesai 🎉

Tidak diperlukan instalasi compiler Assembly atau emulator 8086 tambahan untuk menjalankan aplikasi ini.

## 🚀 Cara Menggunakan

1. Tulis kode Assembly 8086 pada editor.
2. Klik **🛠 Build Code (F9)** untuk melakukan assembly.
3. Klik **▶ Jalankan Emulator (F5)** untuk menjalankan program.
4. Gunakan **F10** untuk menjalankan instruksi satu per satu.
5. Gunakan **Reset CPU** untuk mengembalikan kondisi emulator.

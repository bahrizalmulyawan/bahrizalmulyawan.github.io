Penjelasan singkat mengenai bahasa Assembly dan pemrograman 8086.

Apa itu Assembly?

Assembly adalah bahasa pemrograman tingkat rendah yang menggunakan mnemonic untuk merepresentasikan instruksi prosesor. Program Assembly sangat dekat dengan cara CPU menjalankan instruksi.

Dalam ASM Studio, contoh dan emulator berfokus pada arsitektur Intel 8086 dan lingkungan MS-DOS.

Mengapa belajar Assembly 8086?

CPU

Memahami register, instruksi, flag, dan alur eksekusi CPU.

Memory

Memahami hubungan antara register, alamat memori, stack, dan data.

Machine Code

Melihat bagaimana instruksi Assembly diterjemahkan menjadi machine code.

Debugging

Mengamati perubahan register dan langkah eksekusi satu per satu.

Binary Conversion

 ; ============================================
; Konversi Desimal ke Biner 
; ============================================
ORG 100h

; --- Proses Hitung Nyata (Dibagi 2 berulang kali) ---
MOV AX, 0        ; <--- Angka desimal yang akan dihitung
MOV BX, 2           ; <--- Angka pembagi (karena biner berbasis 2)
MOV CX, 16          ; Kita akan membagi 16 kali agar pas menjadi 16-bit

BAGI_DUA:
    XOR DX, DX      ; (Penting!) Bersihkan register sisa bagi sebelum pembagian
    DIV BX          ; Bagi AX dengan 2. Hasil bagi masuk ke AX, sisa masuk ke DX.
    PUSH DX         ; Simpan sisa bagi (0 atau 1) ke dalam memori Stack
    LOOP BAGI_DUA   ; Ulangi perhitungan ini 16 kali 

; --- Proses Mencetak Hasil ke Layar ---
MOV CX, 16          ; Atur counter untuk mencetak 16 digit bit

CETAK_BIT:
    POP DX          ; Ambil sisa bagi dari stack (otomatis membalik urutan angka)
    ADD DL, '0'     ; Ubah angka mesin (0/1) menjadi teks ASCII ('0'/'1')
    MOV AH, 02h     ; Perintah cetak 1 karakter
    INT 21h
    LOOP CETAK_BIT  ; Ulangi sampai 16 digit tercetak

; --- Cetak huruf 'b' di akhir ---
MOV DL, 'b'
MOV AH, 02h
INT 21h

; --- Program Selesai ---
MOV AX, 4C00h       ; Exit code
INT 21h

Stack dan subroutine

Stack adalah area memori yang digunakan secara LIFO (Last In, First Out). Instruksi PUSH memasukkan data ke stack, sedangkan POP mengambil data dari stack. CALL dan RET digunakan untuk alur subroutine.

PUSH AX
PUSH BX
POP BX
POP AX

Cara memakai ASM Studio

  1. Tulis program Assembly pada editor.
  2. Gunakan Build Code untuk melakukan assembly.
  3. Gunakan Run Emulator untuk menjalankan program.
  4. Gunakan Step untuk melihat eksekusi instruksi satu per satu.
  5. Amati register, simbol, stack, memory dump, dan machine code pada panel debug.

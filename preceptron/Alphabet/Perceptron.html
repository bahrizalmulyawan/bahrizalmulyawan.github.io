Model ini adalah multiclass linear perceptron: 26 unit skor linear, tanpa hidden layer. Setiap kelas memiliki 256 bobot dan satu bias.

Input: x ∈ {0,1}²⁵⁶
Skor kelas k: sₖ = Σᵢ₌₁²⁵⁶ (wₖᵢ × xᵢ) + bₖ
Prediksi: ŷ = argmaxₖ(sₖ), k ∈ {A,B,…,Z}
Update jika salah:
wᵧ ← wᵧ + ηx   dan   wₚ ← wₚ − ηx
bᵧ ← bᵧ + η   dan   bₚ ← bₚ − η
η = 0.1 · y = label target · p = prediksi model

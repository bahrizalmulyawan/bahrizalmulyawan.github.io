Patchfinder — Explanation

Patchfinder adalah visualizer pathfinding berbasis HTML/JavaScript untuk maze grid. Aplikasi memungkinkan pengguna membuat maze, mengatur beberapa Start dan Goal, memilih algoritma pencarian, lalu melihat proses pencarian dan path secara visual.

1. Multi Start / Multi Goal

Marker dipasangkan berdasarkan nomor, bukan berdasarkan jarak:

S1 → G1, S2 → G2, …, Sn → Gn.

Setiap pasangan diproses satu per satu. Jika jumlah Start dan Goal berbeda, hanya pasangan sampai jumlah terkecil yang diproses.

2. Path Tidak Berpotongan

Setelah sebuah pasangan menemukan path, seluruh cell pada path tersebut dimasukkan ke dalam reservedPath. Pencarian pasangan berikutnya dilarang melewati cell yang sudah reserved, kecuali cell tersebut adalah Start atau Goal dari pasangan yang sedang diproses.

Dengan mekanisme ini, path yang sudah selesai tidak dipakai kembali oleh pasangan berikutnya sehingga rute tidak berbagi jalur atau berpotongan pada cell yang sama.

Catatan: Jika maze tidak menyediakan rute bebas untuk suatu pasangan, pasangan tersebut dapat menghasilkan NO PATH atau dilewati agar aturan non-crossing tetap dipertahankan. Sistem tidak memaksa path yang berpotongan.

3. Tombol Acak

Tombol Acak Start / Goal menempatkan marker secara acak pada cell yang bukan wall, tanpa overlap antar marker. Nomor marker tetap menentukan pasangan: marker pertama menjadi S1/G1, marker kedua S2/G2, dan seterusnya.

4. Algoritma

  • Dijkstra
  • A*
  • Breadth-First Search (BFS)
  • Blind Search / DFS
  • Greedy Best-First Search
  • Bidirectional BFS
  • Bidirectional Dijkstra
  • Bidirectional A*
  • Uniform Cost Search (UCS)
  • IDA*

Pada grid tanpa bobot, BFS dan Dijkstra/UCS dapat menghasilkan shortest path. A* menggunakan estimasi Manhattan, sedangkan Greedy Best-First memprioritaskan heuristic.

5. Cara Menggunakan

  1. Buka Patchfinder.html di browser modern.
  2. Pilih ukuran maze dan algoritma.
  3. Atur jumlah Start dan Goal.
  4. Buat atau edit wall sesuai kebutuhan.
  5. Gunakan Acak Start / Goal jika ingin posisi marker baru.
  6. Tekan tombol Run untuk memproses pasangan S1→G1, S2→G2, dan seterusnya.
